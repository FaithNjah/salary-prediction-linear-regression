# Data

`salary_data.csv`: 30 employees from the [Salary Dataset: Simple Linear Regression](https://www.kaggle.com/datasets/abhishek14398/salary-dataset-simple-linear-regression) on Kaggle.

| Column | Description |
|---|---|
| YearsExperience | Years of work experience (1.2–10.6) |
| Salary | Annual salary (about 37,700–122,400) |

The dataset is small, so it's included here to let the project run straight after cloning.
